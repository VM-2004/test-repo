# AI Interview Mocker

## Overview
AI Interview Mocker is an AI-powered interview preparation platform that helps users practice technical and HR interviews. The application generates interview questions, records user responses, and provides instant feedback to improve communication skills, confidence, and interview performance.

## Features
- AI-generated interview questions
- Technical and HR interview practice
- Real-time feedback and evaluation
- User authentication and profile management
- Interview history tracking
- Responsive and user-friendly interface
- Performance analytics and reports
